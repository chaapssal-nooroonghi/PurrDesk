## 변경 사항

메뉴를 열 때 현재 화면 DPI의 Windows 메뉴 글꼴을 다시 읽어 물리 픽셀 단위로 적용합니다. 이전 크기가 남아 있다면 WinForms의 DPI 처리로 여백/항목/아이콘 크기도 갱신합니다. 귀염둥이·트레이·하위 메뉴 모두 적용했습니다. 비어 있는 트레이 메뉴를 처음 열 때 동적으로 추가한 항목이 표시되지 않는 경로도 수정했습니다.

설정창의 DpiForm/DpiFonts는 1.0.10.0과 같습니다. MSIX의 바이트 비교에서 EXE·AppxManifest.xml·AppxBlockMap.xml만 달라졌습니다. 나머지 사진·ONNX·DLL은 같습니다. 1.0.10.0 대비 1,347 bytes 증가했습니다. 기존 GitHub v1.0.5와 Mac 배포 파일은 변경하지 않았습니다.

## Cloud PC에서 할 일

1. **현재 환경부터 확인.** 1.0.10.0 보고서 말미에는 앱·테스트 인증서·관리자 권한과 연결을 유지했다고 되어 있습니다. 현재 상태는 이 빌드 세션에서 확인하지 않았습니다. 검사 세션에 있는 최신 사용자 지시를 따르고, 임의 초기화/재부팅/종료·권한 변경을 하지 마세요. 테스트 인증서 유효기간·앱 버전·배율을 먼저 확인하세요.
2. 숨김 파일을 포함한 기존 사진/설정 데이터를 백업하고 해시를 남기세요. 원본 MSIX 해시를 대조하고 **복사본만** 유효한 테스트 인증서로 서명해 기존 1.0.10.0 위에 업데이트 설치하세요. 원본 파일을 서명하지 마세요.
3. **핵심 재현 순서:** 실제 DPI 240/250% 상태에서 앱을 시작하고 누룽지·찹쌀이 우클릭 메뉴, 트레이 메뉴, 두 귀염둥이 하위 메뉴를 각각 먼저 열고 닫으세요. 설정창도 열어둔 채 앱을 종료하지 않고 실제 DPI 96/100%로 전환하세요. 동일 프로세스에서 메뉴들을 다시 열어 글자/행/아이콘/전체 메뉴 크기와 스크롤 화살표를 확인하세요. 기존 버그는 높은 배율에서 먼저 열었던 메뉴에 나타났습니다. **100% 전환 후 처음 여는 메뉴만 확인하면 안 됩니다.** 트레이의 하위 항목은 루트를 열 때 다시 생성되므로 재사용되는 루트와 새 하위 메뉴를 구분해 기록하세요.
4. 같은 100%에서 앱을 재실행한 화면을 정상 대조로 남기세요. 100→250% 역방향, 125/150/200% 중간 배율 및 각 배율 새 실행도 확인하세요. 실제로 지원하지 않는 중간 배율/혼합 모니터 검사는 미검사로 명시하세요. Chrome 줌을 Windows DPI로 대신하지 마세요.
5. 설정창 네 탭(전환 후 처음 여는 탭 포함), 새 설정창, 크기/뽀모도르/스트레칭/사진 관리·제작창에서 글자·버튼 잘림을 확인하세요. 저장 전 이름/숫자/시간 보존, 취소/저장, 실제 메뉴 명령·드래그·클릭 통과·숨김도 확인하세요.
6. 실제 로그아웃 후 재로그인 자동 시작을 검사하세요. 설치/재로그인 후 사진 해시와 설정 보존을 비교하세요. 사용자 조작에 따른 정상 설정 변경은 구분하세요.
7. Cloud PC의 WACK `10.0.28000.2957`로 전체 재검사하세요. 다음 공식 패키지 경로 방식으로 실행하고 종료 코드뿐 아니라 원본 XML의 전체 결과·PARTIAL_RUN·버전·TEST 24개를 확인하세요.

```powershell
appcert.exe reset
appcert.exe test -appxpackagepath <테스트서명한-MSIX-복사본> -reportoutputpath <새-wack-report.xml>
```

WindowsApps ACL 변경, WACK 검사 제외/결과 편집, 패키지 컨텍스트 주입은 하지 마세요. 과거 설치 경로 검사에서의 ACCESS DENIED 원인이 이번 변경으로 해결됐다고 주장하지 마세요.

**실패·경고·UI 문제가 남으면 심사 제출하지 마세요.** 이 문서는 재검사 인계이며 제출 명령이 아닙니다. 검사 후 환경 정리는 해당 세션의 최신 사용자 지시를 따르고 실제 수행 상태를 보고하세요.

## 돌려줄 증거

보고서, 원본 WACK XML, 설치/자동 시작 결과, 각 메뉴를 어느 배율에서 먼저 열었는지와 전후 화면, HWND DPI/모니터 배율, 사진·설정 해시 대조, 남은 미검사 범위를 주세요. **25MB MSIX는 증거 ZIP에 다시 넣지 마세요.** 이 다운로드 링크와 SHA256으로 같은 원본을 식별하면 됩니다. 인증서/개인키/토큰/사용자 사진 원본은 증거 묶음에 넣지 마세요.
