## 새로 수정한 문제

1. **설정 비동기 저장 중 창 닫기/편집:** Windows 자동 실행 설정 응답을 기다리며 X/Alt+F4로 닫으면 취소 정리가 신규 사진을 삭제하고 나중에 저장이 완료될 수 있었습니다. 저장 중 편집/닫기를 막고, 대기 중 바뀐 타이머 완료 횟수·위치는 저장 직전에 반영합니다.
2. **사진 보정 브러시 위치:** DPI 변경 후 실제 캔버스 크기와 내부 zoom 값이 달라 커서가 가리키는 곳과 지워지는 곳이 어긋났습니다. 실제 화면 크기와 원본 비율로 좌표·커서 크기를 계산합니다.
3. **휴대폰 JPEG 회전:** 직접 등록한 사진의 EXIF 회전 정보가 미리보기/귀염둥이 표시에 반영되지 않았습니다. 사진 만들기와 같은 회전 처리를 공유합니다. 원본 파일은 변경하지 않습니다.

## Cloud PC 검사 순서

현재 설치 버전·실제 배율·유효 테스트 인증서와 사용자 지시부터 확인하세요. 이 빌드 세션은 Cloud PC 상태를 변경하지 않았습니다. 이전 보고서는 환경 유지 상태였으므로 임의 초기화/재부팅/종료·권한 변경을 하지 말고 해당 세션의 최신 지시를 따르세요.

1. 숨김 파일을 포함한 설정/사진을 백업하고 해시를 기록하세요. 원본 해시를 대조하고 **복사본만** 테스트 서명해 기존 설치 위에 업데이트하세요.
2. 새 사진을 추가하고 자동 실행 설정을 바꾸며 저장하세요. 저장이 진행 중인 경우 X/Alt+F4로 닫기·편집이 차단되고 완료 후 정상 닫히는지 확인하세요. 저장 사진이 재실행 후에도 남는지, 일반 취소는 신규 복사본만 정리하는지, 자동 실행 변경이 실제 적용되는지 확인하세요. Windows 응답이 너무 빨라 대기 경로를 관찰하지 못하면 미관찰로 기록하세요.
3. 보정창의 100/125/150/200/250% 배율에서 눈에 보이는 위치를 지우기·복원하고 되돌리기 하세요. 고배율에서 연 창의 실시간 배율 변경과 사진 확대 선택도 확인하세요. EXIF 회전 JPEG를 직접 등록해 목록 미리보기·바탕화면·재실행 후 방향을 비교하세요.
4. **기존 메뉴 DPI 재검사:** 실제 250%에서 누룽지·찹쌀이 우클릭, 트레이와 하위 메뉴를 먼저 열고 닫으세요. 앱을 재시작하지 않고 100%로 바꾼 뒤 같은 메뉴를 다시 여세요. 글자·행·전체 크기·스크롤 화살표·클릭을 확인하세요. 전환 후 처음 여는 메뉴만 보면 기존 문제를 놓칩니다. 트레이 루트는 재사용되지만 하위 항목은 루트를 열 때 다시 생성되는 점을 구분하세요.
5. 역방향과 지원하는 중간 배율, 기존/새 설정창 네 탭·작은 대화상자, 저장 전 입력, 크기/타이머/사진 관리·제작, 드래그/숨김/클릭 통과를 확인하세요. 물리 혼합 배율 모니터 등 지원하지 않는 검사는 미검사로 남기세요.
6. 실제 로그아웃·재로그인 자동 시작, 설정/사진 보존을 재검사하세요. 사용자 조작에 따른 정상 설정 변경은 구분하세요.
7. Cloud PC WACK `10.0.28000.2957`로 다음 공식 패키지 경로 전체 검사를 실행하세요. 원본 XML의 전체 결과/PARTIAL_RUN/버전/TEST 24개를 직접 판독하세요.

```powershell
appcert.exe reset
appcert.exe test -appxpackagepath <테스트서명-MSIX-복사본> -reportoutputpath <새-wack-report.xml>
```

WindowsApps ACL 변경, WACK 제외/결과 편집, 컨텍스트 주입은 하지 마세요. 과거 설치 경로 검사 ACCESS DENIED 원인이 이번 코드 수정으로 해결됐다고 확대하지 마세요.

**실패·경고·UI 문제가 남으면 제출하지 마세요.** 이 문서는 재검사 인계입니다. 검사 후 환경 정리는 해당 세션의 최신 사용자 지시를 따르세요.
